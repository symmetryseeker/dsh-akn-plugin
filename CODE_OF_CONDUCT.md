# AEN Community Code of Conduct — Draft/Pilot project

## Our commitment

We commit to a respectful, harassment-free community for everyone, regardless of identity, background, experience, ability, nationality, appearance, or viewpoint. Technical disagreement is welcome; personal attacks and coercion are not.

## Expected behavior

- Discuss claims with evidence and state uncertainty honestly.
- Give actionable, specific review feedback and assume good faith while checking security boundaries.
- Respect privacy, licenses, consent, embargoes, and requests to remove sensitive data.
- Disclose conflicts of interest and distinguish project governance from popularity or model/vendor advocacy.
- Help newcomers reproduce results without pressuring them to upload private traces.

## Unacceptable behavior

Harassment, discrimination, threats, sexualized attention, doxxing, publishing secrets or private traces, license abuse, deliberate evidence fabrication, and retaliation against reporters are not accepted. Using project channels to coordinate malicious Agent behavior is also prohibited.

## Enforcement

Report conduct issues privately to repository maintainers. Maintainers may edit or remove content, issue warnings, temporarily restrict participation, or permanently ban accounts. Maintainers must avoid conflicts of interest and should document enforcement rationale privately, disclosing only the minimum necessary public summary.

This policy applies in project repositories, discussions, events, and when someone officially represents AEN. Good-faith security research conducted under [SECURITY.md](./SECURITY.md) is protected from retaliation.
