# 1. Positioning / 项目定位

本仓库是 DeepSeek Harness 的可安装插件，同时是 **Agent Experience Network（AEN）与 AEXP 0.1 协议的参考实现**。

核心主张（沿袭 AEN 完整 Spec 的核心禁令）：

- 不把每次工具调用发布成知识；
- 不默认上传原始 Trace；
- 不自动执行远端 Experience。

真正可共享的是**少量经过选择与审阅的任务级经验**：它在什么任务、Model、Harness、环境下成立，证据有多强，怎样复用，何时不要用。

```text
Trace + live Harness Manifest
  → selected TaskEpisode
  → private Experience draft
  → human review / evaluation
  → explicit Promotion
  → Card discovery + budgeted section read
  → Observation / Feedback / Contention
```

# 2. Overall Architecture / 总体架构

## 2.1 Monorepo 布局

```
apps/            cli（本地工作台入口）· hub（Hub 进程/HTTP/Web）· mcp（跨 Harness 工具面）
packages/
  protocol        AEXP schema/校验/JCS digest/DSSE/in-toto/兼容原语
  adapter-dsh     DSH export 解析、Episode 派生、证据缺口、live manifest
  adapter-sample  跨 Harness 适配器示例与一致性证明
  local-store     私有 SQLite 证据存储、检索、精确删除
  workbench       受约束蒸馏、审阅/编辑、本地检索
  evaluation      冻结计划、trials、aggregates、证据等级门禁
  promotion       公共投影、扫描器、图闭包、签名、撤回
  hub             Git 校验、授权 key、PostgreSQL 投影与搜索
  client          Task Capsule、Context Plan、注入观测、反馈
  dsh-plugin      DSH 原生 Definition/Policy/Provider/Tools + 无头评测驱动
schemas/          AEXP JSON Schema（2020-12）
conformance/      valid/invalid/golden-digests 一致性夹具
spec/             AEXP 0.1 协议 + MVP Implementation Profile
fixtures/         DSH 与评测 fixture
```

## 2.2 六组件映射（AEN MVP Spec 第 11 章）

| AEN 组件 | 本仓库 |
|---|---|
| Protocol Core | `packages/protocol` + `schemas/` + `conformance/` |
| DSH Adapter | `packages/adapter-dsh` + `packages/dsh-plugin`（live manifest） |
| Local Workbench | `packages/local-store` + `packages/workbench` + `apps/cli` |
| Public Hub | `packages/hub` + `apps/hub` |
| AEN Client | `packages/client` + `apps/mcp` |
| Minimal Web | `apps/hub` 内的 HTTP/Web 只读面 |

组件只通过 AEXP 对象与明确接口交互：`packages/protocol` 不依赖 DSH/Hub/DB；`hub` 不持有 Harness 执行能力；`client` 在 Hub 不可用时仍可用本地对象。

# 4. Core Concepts / 核心概念

## 4.1 Agent Configuration Cell

经验只在完整适用上下文中有意义：

```text
Agent Configuration Cell
  = Model Fingerprint + Harness Manifest + Effective Context Surface
  + Environment Fingerprint + Policy Snapshot
```

## 4.2 Evidence levels（H0–H4）

| 等级 | 含义 | 最低证据 |
|---|---|---|
| H0 | trace_observed | 一条完整 TaskEpisode |
| H1 | asset_invoked | H0 + 暴露/使用证据 |
| H2 | manifest_attested | H1 + Manifest + artifact digest |
| H3 | counterfactual_tested | H2 + 对照运行 |
| H4 | replicated | H3 + 多环境独立复验 |

MVP 生成/校验 H0–H3，H4 只读。因果 claim 必须 H3。

## 4.3 关键协议对象

`TaskEpisode` · `TraceEvidenceBundle` · `HarnessManifest` · `ArtifactDescriptor` · `RunObservation` · `ExperienceRevision` · `PromotionRecord` · `FeedbackEvent` · `Contention` · `Revocation` · `BenchmarkTask` · `EvaluationTrial` · `EvaluationAggregate`

对象不可变、内容寻址（`sha256` + RFC 8785 JCS）、带 `ObjectRef`；未知可选扩展忽略保留，未知必需能力 fail closed。

# 5. Package Deep-dive / 包职责详解

| 包 | 关键职责 | 边界 |
|---|---|---|
| `protocol` | AEXP schema/类型/JCS/digest/DSSE/兼容原语 | 零 DSH/Hub 依赖 |
| `adapter-dsh` | DSH export → NormalizedEvent → TaskEpisode；EvidenceGapReport；live snapshot | 只输出协议对象，不发布公共内容 |
| `adapter-sample` | Harness 无关示例，证明 conformance 可扩展 | 不改 schema 即可通过 |
| `local-store` | 私有 SQLite；检索；**精确删除**（隐私） | 敏感数据唯一权威源 |
| `workbench` | 受约束蒸馏（逐 claim 证据关联、正反例、limitations）；审阅/编辑 | LLM 反思只作 candidate |
| `evaluation` | 冻结计划/trials/aggregates；H-level 派生 | 不修改 ExperienceRevision |
| `promotion` | private→public 投影、脱敏扫描、图闭包、签名、撤回 | 唯一晋升权 |
| `hub` | Git 校验、授权 key、PostgreSQL 投影/搜索 | 不持有执行能力 |
| `client` | Task Capsule、Context Plan、注入观测、feedback | 远端内容不可信 |
| `dsh-plugin` | DSH 四角色插件 + 无头评测驱动 | 低频控制点采集 |

# 6. DSH Plugin Composition / DSH 插件集成

`cordis.patch.yml` 注册两个插件，四个逻辑角色：

- **Definition**：类型化服务契约；
- **Policy**：本地捕获深度、Skill/资源可见性、网络权限决策；
- **Provider**：权威 Manifest 采集 + 本地证据协调；
- **Tools**：**默认禁用**的 search/feedback 消费面。

Policy/Provider/Tools 使用独立 Cordis fibers——Tools 可移除而不影响 Manifest 采集。配置 Hub URL 不自动授予网络访问；任一设置都不授予公共发布权。

# 7. Data Ownership / 数据权威

| 数据 | 权威源 | 可复制范围 |
|---|---|---|
| 本地证据/审计 | 私有 SQLite | 默认不复制 |
| 公共贡献成员/授权 key | reviewed Git | 按 section policy |
| PostgreSQL | Hub 可重建投影 | 可重建，非权威 |
| Experience 对象 | 不可变 | 投影可重建，digest 不变 |

# 8. Security & Privacy / 安全与隐私

- 信任边界：Adapter 可读私有证据但不可发布；Promotion Gate 唯一可晋升；Hub 不执行 Harness 工具。
- Promotion 重跑 secret/PII/path/license 检查，生成新 target digest，记录 PromotionRecord/RedactionReport。
- Revocation 优先于 cache/index（立即阻止 fetch + tombstone）。
- 消费侧：远端 section 以 untrusted provenance 包装，不覆盖 sandbox/approval/policy。

# 9. Engineering / 工程

- CI：`.github/workflows/aen-ci.yml`（typecheck/build/test/e2e/hub-deployment/postgres/performance）。
- 构建：pnpm workspace；root `prepare` 构建 `@aen/dsh-plugin` bundle；root 依赖仅真正运行时包（ajv/typebox/schemastery 等）。
- 发布：`dsh-akn-plugin` npm 包自包含（dist 内联 bundle），`files` 只含 dist + cordis.patch.yml + README + LICENSE。
- 测试：协议 conformance、多进程 e2e、DSH 插件 host 冒烟、Hub 部署、真 Postgres、性能基准、源码 secret 审计。
